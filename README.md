# Hospital Queue Management System Using C++

## Project Overview
A console-based hospital queue management system developed
using C++. It demonstrates the use of a Queue and Linked List
for managing patient information.

## Features
- Register new patients
- Display all patients
- Call the next patient
- Search patients by ID
- Sort patients by priority
- Dynamic memory allocation using a Linked List

## Data Structures
- Queue
- Singly Linked List
- Node Structure

## Priority
- 1 = Emergency
- 2 = Normal

## Requirements
- C++ compiler (GCC, MinGW, or equivalent)
- C++11 or later

## How to Run

Compile:
g++ main.cpp -o hospital

Run on Windows:
hospital.exe

Run on Linux/macOS:
./hospital
